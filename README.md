# Sahayogi-Student-Support-Hub
Sahayogi — Student Support Hub

Sahayogi is a modern, centralized University Student Support Portal designed to bring academic, administrative, campus, and student-assistance services into one easy-to-use digital platform.

The project addresses a common university problem: students often need to visit different departments, websites, offices, or portals to complete simple tasks such as checking attendance, paying fees, downloading certificates, viewing exam information, contacting IT support, or submitting complaints. Sahayogi combines these services into a single student-friendly interface.
